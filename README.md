# Day 10: Contact Book Using Dictionaries

## Objective

The objective of this project is to develop a simple command-line Contact Book using Python dictionaries. The application allows users to add, search, update, and delete contact information. The project demonstrates practical use of dictionaries and key-value data management.

## Technologies Used

- Python
- VS Code

## Operations Supported

1. Add Contact
2. View Contacts
3. Search Contact
4. Update Contact
5. Delete Contact
6. Exit

## Features

- Stores contact information using a Python dictionary.
- Uses phone number/contact ID as the dictionary key.
- Allows users to add new contacts.
- Displays stored contact information.
- Allows users to search for contacts.
- Allows users to update existing contacts.
- Allows users to delete contacts.
- Validates duplicate contact entries.
- Handles contacts that do not exist.
- Uses separate functions for different operations.
- Provides a simple menu-driven command-line interface.

## Generated Files

- `contact_book.py` – Contains the Python program for adding, viewing, searching, updating, and deleting contact information using dictionaries.
